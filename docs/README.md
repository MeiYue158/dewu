## 评审状态

- 状态：选型建议已确认（2026-10-20），完整设计仍待用户 review
- 实现门槛：PRD、原型、概要设计通过后再开始编码
- 首版定位：独立教学项目，参考得物场景；不声称得物内部接入、上线或业务效果
- 数据边界：正式推荐只能引用带来源和更新时间的可核对数据；虚构目录仅用于测试

## 课程映射

| 课时 | 设计落点 |
|---|---|
| 1-2 | 用户任务、信息架构、指标树、应用骨架 |
| 3-4 | 卡片、事件协议、加载/失败/重试状态 |
| 5-6 | 智能体、工具边界、FastAPI、会话接口 |
| 7-8 | 多品类数据、来源、缺失与无法核实 |
| 9-10 | 多轮约束、澄清策略、冲突恢复 |
| 11-12 | 召回、硬过滤、排序、推荐理由、比较 |
| 13-14 | 离线评测、策略版本、日志、超时与密钥隔离 |
| 15-16 | 端到端验收、架构解释、事实边界 |


## 已确认的设计基线

前后端分离、后端为核心；React/TypeScript + Ant Design、FastAPI、SQLite；移动优先兼容桌面；可配置模型接口，先完整回复再流式；小规模可追溯数据手动导入；项目内详情页优先。具体模型和正式数据来源仍需落实，详见 PRD 第 10 节。
